## 마이페이지

**상단 프로필 영역** (고정): 프로필 이미지·닉네임 표시. '프로필 수정' 버튼(AUTH-02 진입), '회원 탈퇴' 링크(AUTH-03 진입).

**탭 구성**: 관심 아티스트 / 예정 공연 / 다녀온 공연 / 내 문의

| ID | 기능명 | 설명 | 우선순위 | 비고 |
|----|--------|------|----------|------|
| MY-01 | 다녀온 공연 | 내 캘린더에 추가한 공연 중 공연일이 지난 항목을 '다녀온 공연' 탭으로 분리해 기록. 아티스트명·날짜·장소 표시. 페이지네이션, 10건/페이지. | P1 | |
| MY-02 | 관심 아티스트 목록 | 팔로우한 아티스트 목록을 마이페이지 탭에서 조회. 목록에서 바로 팔로우 해제 가능. `/api/artists/following` 재사용. | P1 | ART-04 연동 |
| MY-03 | 예정 공연 목록 | 내 캘린더에 저장한 공연 중 공연일이 지나지 않은 항목을 '예정 공연' 탭으로 표시. 아티스트명·날짜·장소 표시. 페이지네이션, 10건/페이지. `/api/calendar/my` 재사용. | P1 | CAL-02 연동 |

## 데이터 문의

공통 사항: 로그인 필요. 처리 상태 흐름: PENDING(접수) → IN_PROGRESS(처리중) → RESOLVED(완료) / REJECTED(반려). 등록 완료 시 '문의가 접수되었습니다.' 토스트 표시. 동일 대상 ID로 PENDING 상태인 문의 존재 시 재등록 불가.

| ID | 기능명 | 설명 | 우선순위 | 비고 |
|----|--------|------|----------|------|
| INQ-01 | 공연 정보 문의 | 공연 상세 페이지의 '정보 문의' 버튼으로 진입. concert_id 자동 주입, 유형 CONCERT 고정.<br>▸ 문의 대상: 날짜·장소·아티스트 매핑·예매처·포스터 등 공연 정보 오류·누락.<br>▸ 제목·내용 입력 후 등록. | P1 | 로그인 필요 |
| INQ-02 | 아티스트 정보 문의 | 아티스트 상세 페이지의 '정보 문의' 버튼으로 진입. artist_id 자동 주입, 유형 ARTIST 고정.<br>▸ 문의 대상: 프로필·멤버 구성·관련 링크 등 아티스트 정보 오류·누락.<br>▸ 제목·내용 입력 후 등록. | P1 | 로그인 필요 |
| INQ-03 | 셋리스트 정보 문의 | 공연 상세 페이지의 셋리스트 문의 버튼으로 진입. concert_id 자동 주입, 유형 SETLIST 고정.<br>▸ 문의 대상: 셋리스트 오류·누락·미등록.<br>▸ 진입 경로: ① CON-05 구현 후 — 셋리스트 탭 내 '정보 문의' 버튼 ② CON-05 미구현 기간(P2) — 공연 상태가 '공연완료'일 때 공연 상세 하단에 버튼 표시.<br>▸ 제목·내용 입력 후 등록. | P1 | 로그인 필요 |
| INQ-04 | 내 문의 내역 조회 | 로그인 사용자가 자신이 등록한 문의 목록과 처리 상태를 마이페이지에서 확인. 문의 유형·제목·상태·등록일 표시.<br>▸ 문의 상세 클릭 시 처리 결과 및 반려 사유 확인 가능. | P1 | 마이페이지 내 탭 |
